AskDSA | AI-Powered Algorithmic Tutor
AskDSA is a dedicated chatbot that provides expert-level guidance on DSA topics, ranging from basic arrays to complex dynamic programming and graph theory.
Key Features:
DSA Specialized: Fine-tuned system prompts ensure the AI stays focused on technical logic, complexity analysis, and code implementations.
Markdown Support: Uses the marked library and Angular DomSanitizer to render headers, tables, and syntax-highlighted code blocks.
Full-Stack Architecture: Decoupled Frontend (Angular) and Backend (Node.js) for better scalability and security.
Optimized Performance: Implements the latest Gemini 3.5-Flash models for near-instant responses.
Tech Stack:
Frontend: Angular 18+, TypeScript, CSS3, RxJS.
Backend: Node.js, Express.js, Google Generative AI SDK.
Security: Environment variable protection via dotenv and CORS policy management.
